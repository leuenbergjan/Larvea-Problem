How this works & caveats

  • Test assumed: one-way ANOVA on weight, groups of equal size, normally distributed weights with the same SD in every group. Power is computed exactly from the noncentral F distribution (same method as G*Power).
  • Effect size: Cohen's f = SD of the group means ÷ within-group SD. The “pattern” setting converts f into an actual max–min weight difference.
  • Pairwise column: the smallest difference between two specific groups that a post-hoc t-test (pooled error from the ANOVA, Bonferroni-corrected α) detects with the chosen power. Tukey's test needs roughly similar differences.
  • The SD drives everything. Halving the SD halves the detectable difference; doubling the sample size only shrinks it by about 30 %. Reducing variation (same instar, same age, same weighing time) is often the cheapest way to gain power.
  • If you plan a non-parametric test (Kruskal–Wallis), expect to need about 15 % more larvae for the same power.
  • Larvae that die or pupate early reduce n – plan a few extra per group.
